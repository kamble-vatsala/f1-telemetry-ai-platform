Problem Statement & Goal StatementProblem Statement (The "As-Is" Baseline):
During the 2024–2026 F1 telemetry evaluation cycle, the existing monolithic Streamlit application (v1.0) exhibits an average UI rerun latency of 2,800 ms – 4,200 ms per parameter adjustment and requires 6 to 8 manual clicks across 3 tabs (~45–60 seconds) to synthesize a pit-stop undercut decision. Furthermore, cold-start sleep states on community hosting result in 15–30 second wake-up delays, making the system unsuitable for real-time pit-wall and executive operations.Goal Statement (The "To-Be" Target):
Redesign the platform architecture using Google's ecosystem at $0 infrastructure cost to:Reduce interactive telemetry & simulator response latency by over 90% (from ~3,500 ms to less than 250 ms) via a decoupled FastAPI + React architecture on Google Cloud Run.Reduce executive reporting clicks from 8+ clicks to 1 click via an automated BigQuery + Data Studio (Looker Studio) Executive Scorecard.Reduce multi-model race strategy decision cycle time from ~50 seconds to under 5 seconds by deploying a Gemini API Function-Calling "AI Race Engineer" that queries the 10-model ML suite and DuckDB lakehouse autonomously.3.
